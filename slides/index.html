09Heist 4 of 5 · chain link: a valid signature is not safety

ShadowHammer 2019

  • ASUS Live Update trojanized, shipped by the vendor's own update utility to most ASUS machines.

"a sophisticated supply chain attack involving the ASUS Live Update Utility" [9]

PKfail + OpenWrt ASU 2024

Demo 1 · THE FLAW · ~2 min

One line lets the public index win

  • Vendor pip config: --extra-index-url points at the public registry.
  • A higher doorbellino-hal 2.x from the public index resolves over the internal package.
# vendor CI, build job
$ pip install -r requirements.txt \
    --extra-index-url $EXTRA_INDEX_URL
Downloading .../doorbellino_hal-2.0.0.tar.gz

Expected: pip picks the attacker's version.

The console lies

The beacon, on the wire

30Act 5 · What stops it

The five fixes, mapped to the heists

kills heist 2

Index pinning

Allowlist internal names. The public index never gets asked.

kills heists 1+3

Runner egress filter

The build talks to the package index. Nothing else.

kills heist 4

Provenance check

Verify who built the artifact, not just who signed it.

kills the injection

Test after install

Assert the implant slot is zero after pip runs. Live proof: seed-pipeline-poison.sh reorders the pipeline and it goes RED.

the evidence

Flash-and-verify release gate

Dump the flash before the release ships. Monitor for a beacon that should not exist.
